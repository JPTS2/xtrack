# Elements

Learn how individual elements represent fields, geometry and particle transport.
For assembling these elements into a model, use
[line construction](../line_construction/README.md).

| Topic | Lessons |
| --- | --- |
| [Magnets](magnets/README.md) | Physical fields, normalized strengths, model/integrator choices, slicing and bend geometry |

The [collection structure](../README.md#elements) also describes the planned
cavity, map, spatial-transformation and advanced custom-element branches.
Machine-level RF dynamics belongs with RF; apertures have their own subject.
