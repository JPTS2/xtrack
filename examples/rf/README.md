# RF and longitudinal motion

Begin with [longitudinal dynamics](dynamics/README.md): synchrotron oscillations,
buckets, freely accumulating arrival delays, transition crossing and two RF
systems slipping relative to one another.

For individual cavity kicks and transport models, see
[cavity elements](../elements/cavities/README.md). For linearized longitudinal
optics, covariance and revolution periods, see
[longitudinal optics](../optics/longitudinal/README.md); for synchronous operating
points and synchrotron-tune targets, see
[longitudinal matching](../matching/longitudinal/README.md).

Continue with [RF clocks and timing](timing/README.md) for absolute-time cavities,
time delays, frequency steering, phase programs and synchronized frames.
Then explore [acceleration and reference momentum](acceleration/README.md):
ring ramps, LINAC energy gain and optics, and mixed-species reference clocks.
Each example states its model and reference particle; an
ideal longitudinal model does not qualify the shared ring's momentum acceptance.
